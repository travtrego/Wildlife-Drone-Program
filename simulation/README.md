# Simulation

Simulation is the first validation layer for new autonomy behaviors.

Planned contents:
- PX4 SITL configurations
- vehicle-specific simulated parameter sets
- mission scenarios
- fault-injection scenarios
- synthetic perception tests where useful
- regression scenarios for shared autonomy modules

## Rule
No experimental high-level behavior should make its first appearance on a large physical aircraft if it can reasonably be exercised in simulation first.
